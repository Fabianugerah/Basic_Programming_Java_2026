## Tentang Bahasa Java

Java adalah bahasa pemrograman tingkat tinggi yang pertama kali dikembangkan oleh Sun Microsystems dan kini dikelola oleh Oracle. Java dirancang agar mudah dipelajari, aman, dan dapat berjalan di berbagai perangkat tanpa perlu menulis ulang program. Prinsip ini dikenal dengan istilah "write once, run anywhere", yaitu program yang ditulis satu kali dapat dijalankan di sistem operasi mana pun selama perangkat tersebut memiliki Java Virtual Machine (JVM).

Java menggunakan pendekatan pemrograman berorientasi objek, yaitu cara menyusun program dengan memandang setiap bagian sebagai objek yang memiliki data dan perilaku. Pendekatan ini membuat kode lebih terstruktur, mudah dirawat, dan dapat digunakan kembali. Selain itu, Java bersifat strongly typed, artinya setiap data memiliki jenis yang jelas sehingga banyak kesalahan dapat ditemukan sejak program dikompilasi, sebelum program benar-benar dijalankan.

Cara kerja Java cukup unik. Kode yang ditulis oleh programmer terlebih dahulu dikompilasi menjadi bytecode, lalu bytecode tersebut dijalankan oleh JVM. Karena itulah Java tidak terikat pada satu jenis komputer atau sistem operasi tertentu. Java juga memiliki pengelolaan memori otomatis yang disebut garbage collector, sehingga programmer tidak perlu mengatur penggunaan memori secara manual.

Hingga saat ini Java banyak digunakan untuk membangun aplikasi desktop, aplikasi web sisi server, sistem perbankan, aplikasi Android, hingga sistem berskala besar di perusahaan. Karena sifatnya yang terstruktur dan populer, Java sering dipilih sebagai bahasa pertama di perkuliahan untuk melatih logika berpikir dan dasar-dasar pemrograman.
